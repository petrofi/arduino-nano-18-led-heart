# GitHub'a Yükleme

1. GitHub'a giriş yap.
2. Sağ üst `+` > **New repository**.
3. Repository name: `arduino-nano-18-led-heart`
4. Description:
   `Arduino Nano ile 18 LED'li kalp projesi — bağlantı şemaları, lehim rehberi ve animasyon kodları.`
5. **Public** seç.
6. README / .gitignore / lisans oluşturma; paket içinde var.
7. **Create repository**.
8. **uploading an existing file** seç.
9. ZIP'i bilgisayarında çıkart.
10. Çıkan klasörün içindeki tüm dosya ve klasörleri GitHub'a sürükle.
11. Commit mesajı: `Initial release: 18 LED heart project`
12. **Commit changes**.
