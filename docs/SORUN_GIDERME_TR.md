# Sorun Giderme

## Nano görünmüyor
Arduino IDE > Kart Yöneticisi > Arduino AVR Boards yükle.

## COM portu görünmüyor
- Veri kablosu kullan.
- Klon Nano için CH340/CH341 sürücüsünü kontrol et.
- Başka USB portu dene.

## avrdude / stk500 hatası
ATmega328P (Old Bootloader) dene.

## Bir LED yanmıyor
Polarite, 220 Ω direnç, lehim ve ilgili Nano pin kablosunu kontrol et.

## Buton çalışmıyor
A6 buton test kodunu kullan.
